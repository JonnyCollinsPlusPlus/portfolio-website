UserAPI is a C# .NET API that handles user logins. It authenticates users with JWTs, stores data in a PostgreSQL database, hashes passwords with BCrypt, and is tested automatically with xUnit and GitHub Actions. It is deployed via Render and Neon, and you can try it live.

Main features

JWT authentication

Users are authenticated with JSON Web Tokens.

PostgreSQL backend

User data is stored in a PostgreSQL database.

BCrypt password hashing

Passwords are hashed with BCrypt.

Automated testing

xUnit tests run automatically through GitHub Actions.
