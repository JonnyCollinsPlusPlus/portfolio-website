UDPNetworking

A general purpose UDP networking library, built in C++ with SDL3 and SDLNet, with ImGui for the demo.

  • C++
  • SDL3
  • SDLNet
  • ImGui
  • UDP
View on GitHub

After finishing my University Game Networking Project, I felt that the networking code could have been improved, and following the recent full release of SDL3, I decided to make a games networking library. I wanted to keep the advantages of my original code: fast messages sent over UDP, and value interpolation. However the code needed a full refactor to generalise the data streaming. I added all of these features, and made a small demo, which can be found in the GitHub repo.

Main library features

UDP data streaming

Fast messages sent over UDP.

Acknowledgements

An option to acknowledge messages, TCP style.

Value interpolation

An option to interpolate received values.

Custom data

An option to transmit your own data.

What's next

While the library works on its own, there is more I would like to do with this project.

Engine wrappers

An engine-specific wrapper, such as a Unity extension, so the library can be used in an engine without extensive setup.

Better documentation

Clearer docs for anyone using the library.

NAT traversal

Support for connecting players behind NATs.

A bigger demo

A more extensive demo of what the library can do.
